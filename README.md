# محفظة تجريبية — للمزح فقط

تطبيق iPhone مستقل بواجهة عربية واتجاه من اليمين لليسار. الرصيد قابل للتعديل بالدينار البحريني مع ثلاث خانات عشرية، وبطاقة وهمية ببادئة DEMO وآخر أربعة أرقام قابلة للتعديل. البيانات محفوظة محليًا فقط. لا يتصل التطبيق بأي خدمة ولا يدعم الدفع أو التحويل أو إصدار الإيصالات، ولا يتبع BenefitPay أو أي بنك.

## تنزيل IPA من GitHub

1. افتح تبويب **Actions** ثم **Build iPhone IPA (unsigned)**.
2. انتظر اكتمال البناء باللون الأخضر، أو اضغط **Run workflow** لتشغيله يدويًا.
3. من **Artifacts** نزّل **DemoWallet-unsigned-IPA** وفك ملف ZIP لتجد `DemoWallet-unsigned.ipa`.

**الملف غير موقّع ولا يُثبّت مباشرة على iPhone.** يحتاج توقيعًا صالحًا باستخدام حساب Apple وأداة توقيع مثل AltStore أو Sideloadly على جهازك، بحسب توافق الأداة وشروط Apple. لا تضع كلمة سر Apple أو شهادات التوقيع في المستودع.

## فتحه في Xcode على Mac

يتطلب Xcode مع iOS SDK وXcodeGen:

```sh
brew install xcodegen
xcodegen generate
open DemoWallet.xcodeproj
```

للتثبيت مباشرة من Xcode اختر فريقك في Signing & Capabilities واضبط `CODE_SIGNING_ALLOWED` إلى `YES` واختر معرّف حزمة فريدًا، ثم شغّل التطبيق على جهازك. إخراج IPA موقّع يعتمد على عضويتك وشهاداتك وملفات provisioning المتاحة في Apple.

عبارة «للمزح فقط» لا تعني حصانة قانونية. لا تستخدم النموذج لإيهام الآخرين بوجود رصيد أو إثبات دفع حقيقي.
